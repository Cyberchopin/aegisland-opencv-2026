OpenCV 5 converts visual observations into motion, texture, confidence and candidate-zone evidence. A deterministic agent combines that evidence with simulated telemetry and safety policy. It can change the next simulated intent, request CLAHE enhancement and another observation, or enter human review. The trace binds observations, reasons and simulated commands. Human control is used where policy requires it; emergency reserve is not described as universally waiting for approval.

Local artifacts include an annotated video, decision trace, dashboard and provenance hashes. A separate post-run cloud path stores evidence in the bounded recorded test through an IAM-authenticated API, Lambda, conditional S3 writes and a verified DynamoDB index. The first live storage verification failed with 503. The corrected run passed 34/34 requests and cloud readback; all nine reconstructed files matched, and test resources plus the exact staging object were cleaned. Cloud responses never change the simulation's safety decisions.
