We reused a clean, pinned AegisLand core for perception, policy, approval handling and synthetic simulation. The competition repository adds an isolated local entry point, artifact validation and hashes, a versioned evidence protocol, deterministic failure-injection tests and submission tooling. The core safety policy is unchanged.

The tested environment uses Python, OpenCV 5 and NumPy. OpenCV runs the actual image/video workload, including optical flow, motion compensation and enhancement. Boto3/Botocore support the separate evidence backend. The reviewed AWS design has nine resources and one scoped Lambda execution role/inline policy. Tests reproduce the reserved-word expression defect and reject partial writes, malformed acknowledgements and corrupted completion flags. No new infrastructure, IAM expansion or speculative GPU feature was added for the correction.
